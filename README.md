# LeadLoop CRM

**An agency CRM that runs inside Microsoft 365.** LeadLoop captures every lead, drafts and tracks proposals, reminds the team to follow up, and keeps each client's full history in one place.

## What it solves

| Agency problem | LeadLoop |
|---|---|
| Leads arrive from everywhere and get lost | Website form, shared inbox, referrals and an API feed one pipeline: de-duplicate, AI summary, round-robin assignment, Teams alert, auto-reply |
| Proposals take hours and vanish | Templates, a service catalogue and an AI first draft, sent as a tracked web link the client accepts in one click |
| Follow-ups are forgotten | Stale-deal alerts, "opened 3 times today — call now" signals and a daily Teams digest |
| Client history is scattered | Outlook email and meeting sync, SharePoint files, proposal milestones and a one-click AI client brief |

## Built with

Dataverse · Power Apps (model-driven) · Power Automate · AI Builder · Power Pages · PCF (React + Fluent UI) · Microsoft Teams · Outlook · SharePoint
